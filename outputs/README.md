# outputs/

Generated by the pipeline. Media files (keyframes, narration, music, clips, films) are not committed
to keep the repository small; run `python pipeline/run_all.py` to regenerate them, or see the film
links in the report. Text artefacts stay in git so reviewers can read them:

- `timeline.json`: shot timings derived from the narration lengths
- `subs/film.srt`, `subs/film_am.srt`: English and Amharic subtitles
- `subs/*.ass`: styled subtitles burned into the films
